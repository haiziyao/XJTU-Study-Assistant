# 西安交通大学2015年招收推荐免试研究生章程

西交研〔2014〕58 号


根据国家和教育部的有关政策法规和文件精神，特对我校2015年招收推荐免试研究生工作制定本章程。


**一、招收免试研究生的基本条件**


凡拥护中国共产党的领导，愿意为社会主义现代化建设服务，品德良好，遵纪守法，并经教育部“中国研究生招生信息网”上“推免服务系统”确认的获得推荐免试资格的优秀应届本科毕业生，满足下列条件之一者，通过面试考核，可被招收为我校研究生：


1. 所在学校为“985”院校；


2. 所在学校为“211工程”院校，综合成绩排名前10%；


3. 其它高校的重点学科（国家级）或2012年学科排名前20%学科中综合成绩排名前5%，或优势学科综合排名前3%，且国家英语六级达到425分。


若在国家级竞赛中获得较高层次奖励、或在正式刊物已发表过论文或有社会实践经历且获得优良评价者可优先招收。


**二、推免生的注册报名**


1. 注册、提交基本信息：凡申请攻读我校硕士研究生的推免生，按教育部通知的时间，登录“中国研究生招生信息网”（[http://yz.chsi.com.cn](http://yz.chsi.com.cn/)或[http://yz.chsi.cn](http://yz.chsi.cn/)） “推免服务系统”进行注册，填写并提交个人基本信息及上传本人照片；


2. 报名：基本信息提交成功后，方可进入报名界面，按要求填报其它信息，备注字段中上传本人成绩单、英语等级证书（扫描件或照片）等附件，并填写获奖、发表论文、社会实践评价等证明个人能力和综合素质的相关信息，也可填报导师信息；


3. 申请者应对上述报考信息仔细核对，一经提交，将无法更改；


4. 推免生在报名时须按规定缴纳报名费，未缴费视为报名无效。


**三、推免生的面试考核**


1. 由申报学科所在的学院对申请人基本信息进行形式审核，确定拟参加面试考核人员名单；


2. 所在学院须在推免生申请报名后的48小时内发送面试通知。在此期间，申请人应随时关注“推免服务系统”的信息；


3. 申请人须在面试通知发出24小时内接收复试通知并作出回应，按规定时间参加面试，否则视为放弃申请；


4. 面试考核由学院统一组织，按照学院事先公布的《面试实施细则》进行。


**四、预录取与正式录取**


1. 面试通过者，由学院向申请人发送预录取通知，请申请人关注“推免服务系统”；


2. 申请人须在预录取通知发出24小时内回应接收预录取，接收者即被我校正式录取为2015年硕士研究生，否则视为放弃录取资格。


**五、新生奖学金**


被我校录取的推免研究生，根据所在学校的推荐排名和面试情况进行综合评定，可分别享受特等、一等、二等新生奖学金，在注册入学后一次性发放。


**六、其它事项**


1．已被我校录取的推荐免试研究生，应承诺不再列入本科就业计划，不报名参加当年硕士生入学统一考试；


2．已录取的推免研究生，如在2015年7月31日前未获得学士学位或必修课不及格，将被取消录取资格；


3．如因申请人提供的信息和材料不真实或存在诚信问题而被录取的，任何时候一经发现将取消申请人录取资格或学籍，后果由申请人自己负责；


4. 体检不符合规定者将被取消录取资格，体检工作将在10月中下旬进行，请留意我校研招网（http://gs.xjtu.edu.cn/zhaos）的具体通知；


5. 我校将于2015年6月份向被本校录取的推免研究生发放录取通知书。
