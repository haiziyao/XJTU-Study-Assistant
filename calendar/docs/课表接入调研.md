# 课表接入调研：XJTUToolBox 是怎么做的

> 来源：本地克隆 `/Users/derivation/Desktop/Project potato/.refs/XJTUToolBox`（HEAD `acc8e1e`，浅克隆无历史）。
> 目的：为「把学校课表变成日历日程」确定数据源、算法与映射方案。
> 结论：**可行，但有两个必须先承认的硬伤——学期起始日与总周数没有可靠接口**。

## 1. 数据源（本科课表已经不是教务系统了）

| 优先级 | 来源 | 接口 | 前置条件 |
| --- | --- | --- | --- |
| **P0 主源** | 新版考勤系统 | `GET https://bk-kq.xjtu.edu.cn/sa/student/service/timetable/weekly?semesterId=<id>` | CAS 登录 + `X-Business-Token`；**校外必须 WebVPN** |
| P0 学期列表 | 同上 | `GET .../sa/student/service/timetable/semesters` | 同上（**只有当前学期给 `startDate`**） |
| P0 换 token | 同上 | `POST .../sa/auth/cas/exchange` body `{loginRequestId, ticket}`（取自 CAS 回调 URL） | CAS 登录后 |
| P1 回退 | 教学服务平台 | `POST https://js.xjtu.edu.cn/server/onlineSchedule/dataList`，body `{xnxqdm:"2025-2026-2", skzc:"<第几周>"}`，**逐周一个请求** | CAS → `loginCas` → `TOKEN-AUTH`；不支持 WebVPN |
| P1 研究生 | gmis | `GET https://gmis.xjtu.edu.cn/pyxx/pygl/xskbcx`（HTML，正则解析 `td_<星期>_<节次>`） | gmis OAuth |
| P2 考试 | 新教务 jwxt | `POST .../studentWdksapApp/modules/wdksap/wdksap.do`，form `XNXQDM=<term>, *order="-KSRQ,-KSSJMS"` | jwxt cookie |
| ~~弃用~~ | 新教务课表 | `POST .../wdkb/modules/xskcb/xskcb.do` | **HEAD 里是死代码（零调用者）**，文档已过期 |

考勤 `weekly` 的原始字段（**没有课程代码/学分/教学班**）：

```
courseName  "高等数学B(1)"
teacherName "张三"
classroomName "5-1w32"
dayOfWeek   1（1=周一）
startSection 3   endSection 4（节次，连堂就是起止跨多节）
weekRanges  "1-16"   ← 周次字符串
```

响应外壳统一 `{code, message, data}`，`code !== 0` 视为业务错误。

## 2. 节次 → 时刻（硬数据，直接抄）

11 节，分块：上午 1-4、下午 5-8、晚上 9-11。**5 月起至 9 月为夏季作息**（`month ∈ {5..9}`），第 1-4 节两套完全相同，第 5 节起不同。

| 节 | 冬季 | 夏季 |
| --- | --- | --- |
| 1 | 08:00–08:50 | 同 |
| 2 | 09:00–09:50 | 同 |
| 3 | 10:10–11:00 | 同 |
| 4 | 11:10–12:00 | 同 |
| 5 | 14:00–14:50 | **14:30–15:20** |
| 6 | 15:00–15:50 | **15:30–16:20** |
| 7 | 16:10–17:00 | **16:40–17:30** |
| 8 | 17:10–18:00 | **17:40–18:30** |
| 9 | 19:10–20:00 | **19:40–20:30** |
| 10 | 20:10–21:00 | **20:40–21:30** |
| 11 | 21:10–22:00 | **21:40–22:30** |

连堂课取「首节开始 → 末节结束」。跨 9/10 月的秋季学期下午课时间会变，所以**必须逐条按日期选表**，不能整学期用一套。

## 3. 周次

- 上游把周次压成一个位图字符串 `SKZC`（`"1111001111"` → 第 1,2,3,4,7,8,9,10 周），天然能表达单双周与不连续周。
- **但仓库里没有任何单双周逻辑**：研究生解析函数遇到 `1-16单周` 会因为 `int("16单")` 抛错而**静默丢掉整段**（我逐字跑过该函数验证：`1-16单周 → []`，即这门课直接不入库）。
  → 我们实现时必须**显式支持 `单/双` 后缀与 `(单)/(双)` 写法，且解析失败要报错而不是产出空周次**。

## 4. 学期起始日与总周数（最大的风险）

- 起始日在线来源只剩**考勤系统当前学期**的 `startDate`；`one2020` 电子校历**已废弃**（固定返回空数组），jwxt 的 `XQKSRQ`、ywtb 的猜算法在 HEAD 里都是**零调用者**。
- 历史学期基本拿不到起始日（XJTUToolBox 还有个 bug：`getNearTerm()` 永远返回当前学期，却拿它当所选学期的起始日）。
- **总周数没有任何接口**：参考实现硬编码「普通学期 22 周、`-3` 小学期 8 周」。**本项目取标准学期 18 周、小学期 8 周**（22 周会把学期结束日算到次年 2 月）。
- 因此我们的设计必须把起始日当**用户资产**：本地持久化、按学期缓存、允许手改、导入前校验（必须是周一、算出来的日期要落在该学期区间内）。

## 5. 数据模型与映射建议

XJTUToolBox 的做法是 **一门课每周一行**（1-16 周 = 16 行，`week_number` 是列，没有周次列表），ICS 导出也是每周一个 VEVENT。

给我们的映射方案（结论：**用 `Schedule` 展开成逐周记录，不要用单条 `repeat`**）：

| 我们的字段 | 取值 |
| --- | --- |
| `date` | `学期起始周一 + (周次-1)*7 + (星期-1)`（ISO：1=周一） |
| `startTime` / `endTime` | 按该条日期选冬/夏表；连堂取首节 start → 末节 end |
| `title` | 课程名 |
| `location` | 教室（没有就不写） |
| `tags` | `['课表','xjtu','term:2025-2026-1','teacher:张三','week:7']` |
| `reminders` | 上课提前 15 分钟；考试提前 30 分钟 |
| `externalId` | `xjtu:{term}:{hash8(课程名\|教师\|星期\|节次\|教室)}:{week}` |

**为什么展开而不是 `repeat`**：

1. 我们的 `repeat` 没有 `exceptions`/EXDATE 字段，**调课、停课、放假都改不了某一天**；
2. `interval: 2` 只能表达等差数列，`{3,5,7,11,13}` 这类不连续周表达不了；
3. 夏冬作息不同，`repeat` 的一条记录只能有一个固定 `startTime`；
4. 数据量很小：18 周 × ~15 门 ≈ 270 条/学期。
5. 与参考实现一致，且 `externalId` 里带 `week` 后天然逐条幂等。

压缩成 `repeat` 只作为**显式开关**（仅当周次连续或整奇偶、且学期内无节假日排除、无单日改动时），默认关闭。

## 6. 落地清单

1. `src/server/timetable/periods.js`：冬/夏两套 11 节时刻表 + `isSummerTime(date)` + `getClassTime(start, end, date)`。
2. `src/server/timetable/term.js`：学期编号解析、起始日推断（9 月第一个周一 / 离 3·1 最近的周一）、`weekToDate` / `dateToWeek`、总周数默认值。
3. `src/server/timetable/weeks.js`：周次字符串解析（**支持单双周**）+ 位图互转。
4. `src/server/timetable/sources/attendance.js`：学期列表 + `weekly` 课表 + CAS 换 token（可复用现有 `src/server/lms/` 的 HTTP 客户端与 CAS 状态机）。
5. `src/server/timetable/toCalendar.js`：中间态 → 逐周 `Schedule`（含 `externalId`、提醒、节假日过滤），预览/应用两步，与思源学堂同步同一套「先预览后写入」交互。
6. 存储：`data/timetable-terms.json`（学期 → 起始周一）+ 课表原始缓存。
7. 界面：思源学堂视图旁边新增「课表」视图（或并入思源学堂视图的第二个页签）：选学期 → 拉课表 → 预览 → 同步到日历。

## 7. 风险

- **校外必须 WebVPN**，且 WebVPN 的域名加密是私有实现（AES-CFB，key=iv=`wrdvpnisthebest!`），学校一改就废；token 有时效。
- 课表主源**迁移过一次**（教务 → 考勤），文档还写着旧接口；`externalId` 要带源标识，换源时整体替换而不是重复建记录。
- 没有课程代码/学分/教学班：要这些只能拿全校课程目录按「课程名+教师」启发式匹配，可能错配。
- 同时段撞车（同一格两门课）需要显式策略；参考实现是「后者覆盖前者」，等于静默丢数据，不建议照抄。
- 作息切换（5-9 月为夏季）在展开模式下必须逐条按日期选表，否则 9/10 月下午课时间会漂。

## 8. 明确未找到的部分

- 调课/停课/补课的系统化建模（只有「按周删 + 按周加」与手填课）。
- 历史学期起始日的可靠在线来源（`one2020` 已废弃，另两条是未验证的死代码）。
